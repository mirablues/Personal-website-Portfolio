Alberta January 2026: Temperature by Weather Station

An interactive Leaflet map visualizing mean January temperatures across 83 weather stations in Alberta—built entirely in R, exported as a self-contained HTML widget.

R / Leaflet dplyr htmlwidgets Climate Data Interactive Viz

Project Overview

Alberta in January is cold—but not uniformly so. This project maps monthly mean temperatures from Environment Canada's climate station network across the province, turning a spreadsheet of raw meteorological readings into a spatially navigable, click-to-explore web map.

Each circle marker encodes a station's mean temperature through color—deep blue for the coldest readings in the north, shifting through white toward warm-toned red for stations closer to 0°C. Hovering reveals the station name and mean temperature; clicking opens a popup with the full range: max, min, and coordinates.

Technical Implementation

Data Cleaning

The raw CSV contained 86 station records. Three stations had missing mean temperature values (Tm) and were excluded using dplyr::filter(). Station names were normalized from ALL CAPS to Title Case using tools::toTitleCase() for cleaner popup labels.

Colour Encoding

A five-stop diverging palette maps the temperature domain (−22°C to 0°C). Deep navy anchors the coldest end; white sits near −11°C; deep red approaches 0°C. This makes the north–south gradient immediately legible without referencing the legend.

# Define colour scale (blue = cold → red = warm) temp_pal <- colorNumeric( palette = c("#08306B", "#9ECAE1", "#FFFFFF", "#FC9272", "#99000D"), domain = c(-22, 0) ) # Build map with popup on click, label on hover alberta_map <- leaflet(data = alberta_data) %>% addProviderTiles(providers$CartoDB.Positron) %>% setView(lng = -114.5, lat = 55, zoom = 6) %>% addCircleMarkers( lng = ~Long, lat = ~Lat, radius = 8, fillColor = ~temp_pal(Tm), fillOpacity = 0.9, color = "white", weight = 1, label = ~paste0(station_name, ": ", Tm, "°C"), popup = ~paste0( "<b>", station_name, "</b><br>", "Monthly mean: <b>", Tm, "°C</b><br>", "Max: ", Tx, "°C | Min: ", Tn, "°C" ) ) %>% addLegend("bottomright", pal = temp_pal, values = ~Tm, title = "January 2026<br>Mean Temp (°C)") # Export as self-contained HTML saveWidget(alberta_map, "alberta_temperature.html", selfcontained = TRUE)

Export Strategy

The map was saved using htmlwidgets::saveWidget(selfcontained = TRUE), which bundles all JavaScript dependencies into a single portable HTML file—no server required, embeddable anywhere via iframe.

Observations

  • A clear north–south gradient. Northern stations (Peace River region) recorded the coldest means, while stations in southern Alberta and the Foothills zone stayed closer to −5°C—reflecting both latitude and Chinook wind influence.
  • The coldest reading: −20.8°C. The warmest: −0.3°C. A 20.5°C spread across a single province in a single month illustrates how geographically heterogeneous Alberta's climate actually is.
  • Data gaps are meaningful. Three stations lacked valid monthly means, likely reflecting sensor outages or incomplete reporting periods—a reminder that climate datasets are never perfectly clean.
