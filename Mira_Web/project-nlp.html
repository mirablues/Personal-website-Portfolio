Project Overview

Can code reveal the hidden biases in code itself? This project applies Python-based Natural Language Processing (NLP) to analyze Tara McPherson's influential essay, "Why Are the Digital Humanities So White?".

By building a custom text mining pipeline, I extracted key thematic patterns to validate whether computational frequency analysis can accurately capture complex cultural arguments regarding race and technology.

The NLP Pipeline

I developed a complete workflow using Python's NLTK library to process raw text into quantifiable data. The pipeline includes:

  • Tokenization: Segmenting text into discrete units.
  • Filtering: Removing "stop words" and applying RegEx to isolate alphanumeric content.
  • Lemmatization: Normalizing words (e.g., converting "systems" to "system") for accurate counting.
# Core Logic Snippet words = word_tokenize(text_data.lower()) filtered_words = [ lemmatizer.lemmatize(word) for word in words if word not in stop_words and content.match(word) ] word_count = collections.Counter(filtered_words) top_words = word_count.most_common(50)

Critical Reflection

This project was not just about coding; it was about critique. As McPherson argues, digital tools are never neutral—they reflect the culture of their creators.

“This project reinforced that while computational methods provide powerful analytical capabilities, they must be wielded with critical awareness of their limitations and embedded biases.”

My analysis revealed that while the algorithm successfully identified technical terms like “UNIX” and “modularity,” it struggled with rhetorical nuance. This highlights the necessity of combining quantitative methods (coding) with qualitative reading (humanities).
