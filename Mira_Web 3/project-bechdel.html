The Bechdel Test Analysis

Investigating gender representation in 1,794 films through relational database design and SQL analysis.

MySQL Python (Pandas) TMDB API Data Visualization

Project Overview

Does the gender of a director affect a film's portrayal of women? Do movies that pass the Bechdel Test actually earn less at the box office?

This project constructed a relational database from scratch to analyze gender mechanics in cinema (1970-2013). By integrating Kaggle datasets with the TMDB API, I examined correlations between female representation and financial success.

Methodology & Architecture

Database Schema

Designed a normalized relational database (3NF) containing four interconnected tables to minimize redundancy:

  • Movies: Core metrics (Budget, Revenue, Year, Test Results).
  • People: Director/Actor metadata and gender identifiers.
  • Cast_Bridge: Many-to-many relationship handling top 5 billed actors per film.
  • Genres: Classification lookups.

Data Engineering

The raw data from Kaggle contained significant inconsistencies. I wrote a Python script to verify records against the TMDB API, manually correcting 81 mismatched entries and removing duplicates before SQL ingestion.

SQL Implementation

Below is a query used to analyze the "Director Effect" — verifying if female directors produce more movies that pass the Bechdel test.

SELECT d.director_gender, COUNT(*) AS total_movies, SUM(m.test_result = 'PASS') AS passing_count, -- Calculate percentage ROUND(SUM(m.test_result = 'PASS') * 100.0 / COUNT(*), 1) AS pass_rate FROM movies m JOIN details d ON m.imdb_id = d.imdb_id GROUP BY d.director_gender ORDER BY pass_rate DESC;

Key Findings

  • The Director Effect: Films directed by women had an 80% pass rate, compared to only 41.8% for male directors.
  • Budget Gap: Movies that failed the test had significantly higher budgets (Avg $50.4M) than those that passed ($37.9M), suggesting industry investment bias.
  • Quality Paradox: Despite lower budgets, films passing the Bechdel test maintained comparable IMDb ratings (6.74 vs 6.59), proving that female-centric narratives do not compromise audience reception.
